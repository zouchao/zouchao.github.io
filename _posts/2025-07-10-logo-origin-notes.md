本站每个浏览器标签页里都藏着一个小图标：一顶宽檐帽、一张人脸、一条盘成一笔的蛇。见过它的朋友不止一次问过我画的到底是什么，我也零散解释过好多回——索性一篇写清楚。它不是随手涂鸦：每一笔都有来历，凑在一起，正好是一份压缩过的自我介绍——我最喜欢什么、我属什么、我叫什么、我从哪里入的行。

![我的 logo：戴宽檐帽的人面蛇身，盘成一笔](/assets/img/favicons/web-app-manifest-512x512.png)

## 帽子：海贼王里艾斯的那顶

logo 最先定下来的是帽子。原型是《海贼王》里的艾斯：那顶橙色宽檐牛仔帽，帽冠凹下去一块，帽檐上缀着两个圆徽章——一个笑、一个哭——是他除了脸之外最有辨识度的东西。画自己的时候，我先把这顶帽子扣了上去：宽檐、帽冠的凹口、乃至两个圆徽章在帽上的位置，都按原样保留。至于徽章里的内容被我换成了什么——先卖个关子。

## 人面蛇身：89 年生，属蛇

摘掉帽子，这个形象是"人面蛇身"：上面一张脸，下面没有腿，整个身体是一条盘着的蛇。这来自我的属相：1989 年生，己巳年，属蛇。把属相做成身体，logo 从落笔那刻就是站得住的。

顺带一说，"人面蛇身"并不是我的发明：神话里的伏羲女娲、汉画像石上的造像，正是这个形状——人脸、蛇躯、尾巴交盘。我画自己的属相，算是误打误撞撞上了一个古老得多的原型。

## z 和 c：邹超

再把脸和身体分开看，里面藏着两个字母：

- 鼻子和嘴巴的位置，是一个小写的 **z**；
- 蛇身是一个没收口的 **c**，末尾还甩着一小截蛇尾。

z 和 c，是我名字邹超（ZouChao）的首字母。z 放在嘴上——一个人说话、被人称呼的地方；c 做成身体——整个形象的主干。名字这样写进形象里，logo 就成了我的替身：你在哪里看见它，就是在哪里看见我。

## `<?` 和 `?>`：PHP 的青春

现在揭晓关子：帽子上那两枚圆徽章换成了什么？脸上的眼睛、耳朵又是什么？答案是一对 PHP 标签——

- 脸两侧支出的两个三角形：左边是 `<`，右边是 `>`；
- 两只眼睛是两个 `?`：问号的上半钩正好落在艾斯帽子两枚圆徽章的位置，下面一点落在脸上做眼珠，一笔两用；
- 整张脸从左往右读：`< ? ? >`，也就是 `<?` 和 `?>`——PHP 的开标签与闭标签。

PHP 是我工作最早使用的语言。那会儿每段脚本都以 `<?php` 开头、以 `?>` 收尾，两个符号写了些年头，写成了我对"程序从哪里开始、到哪里结束"的肌肉记忆。后来换了语言、换了栈，画 logo 的时候还是把它们刻在脸上——等于说：不管如今手里用的东西怎么换，入这行的入口一直在那儿。想考古的，博客里还留着那个年代的文章，比如[《安装 Laravel Homestead 遇到的坑》]({% post_url 2015-10-26-vagrant-box-add-laravel-homestead %})。

## 尾声：把 logo 念出来

四组来历收进一张表：

| 部位                 | 来历                                           |
| -------------------- | ---------------------------------------------- |
| 帽子                 | 《海贼王》艾斯的牛仔帽，徽章位置保留、内容换掉 |
| 身体                 | 1989 己巳年属蛇，所以人面蛇身                  |
| z / c                | 姓名邹超的首字母：z 做鼻嘴、c 做蛇身           |
| 耳朵、眼睛、帽子徽章 | PHP 开闭标签 `<?` 与 `?>`                      |

最喜欢什么、属什么、叫什么、从哪里入的行——四句话压成几笔，挂在浏览器标签页里，陪着我打开的每一个页面。

所以下次在标签页里看见这条戴帽子的小蛇，不妨用 PHP 的方式把它念出来——

```php
<?php echo "ZouChao, 属蛇, 戴艾斯的帽子"; ?>
```

——毕竟从头到尾，我就是把自己包在一对 PHP 标签里的。
